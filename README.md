# 🚀 Cyberbullying Detection & Toxicity Prediction

## 📌 Overview

This MSc project focuses on detecting cyberbullying in social media text using Machine Learning and NLP techniques.

The system combines classical machine learning models with transformer-based deep learning to classify harmful online content and predict toxicity severity.

---

## 🎯 Features

- Multi-class cyberbullying classification
- Toxicity prediction
- ML vs Deep Learning comparison (DistilBERT)
- Explainable AI using SHAP & LIME
- Streamlit web application

---

## 🛠 Tech Stack

Python | Scikit-learn | Transformers | PyTorch | NLTK | SHAP | LIME | Streamlit

---

## 🧠 Models Used

### Classification
- Logistic Regression
- Random Forest
- Naive Bayes
- Linear SVM
- Ridge Classifier
- DistilBERT

### Regression
- Linear Regression
- Random Forest Regressor
- Gradient Boosting
- KNN Regressor
- MLP Regressor
- XGBoost

---

## 📊 Key Capabilities

- NLP preprocessing & TF-IDF feature extraction
- Multi-output toxicity prediction
- Explainable AI visualizations
- Real-time text analysis
- Web-based deployment

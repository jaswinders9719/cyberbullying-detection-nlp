# 🚀 Cyberbullying Detection & Toxicity Prediction

## 📌 Overview
This MSc project focuses on detecting cyberbullying in social media text using Machine Learning and NLP techniques.

---

## 🎯 Features
- Multi-class classification of cyberbullying
- Toxicity prediction
- ML vs Deep Learning (DistilBERT)
- Explainable AI (SHAP & LIME)
- Streamlit web app

---

## 🛠 Tech Stack
Python | NLP | Scikit-learn | Transformers | SHAP | LIME | Streamlit
